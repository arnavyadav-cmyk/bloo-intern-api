# Bloo Intern API

A simple REST API built using FastAPI as part of my Software Engineering Internship.

## Features

- GET endpoints
- POST endpoints
- Path Parameters
- Query Parameters
- Pydantic Models

## Tech Stack

- Python
- FastAPI
- Uvicorn

## Run the project

```bash
uvicorn main:app --reload
```
